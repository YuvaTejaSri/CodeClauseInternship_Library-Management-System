# 📚 Library Management System (Python)

## 📌 Overview
A command-line based Library Management System developed in Python.  
The application allows basic library operations such as managing books, issuing and returning books, and maintaining records.

This project was built during internship practice to strengthen Python programming and structured application development skills.

---

## ✨ Features
- 📖 Add and manage books  
- 👤 Manage users  
- 🔄 Issue and return books  
- 🗂️ Record maintenance  
- 💻 Simple CLI interface  

---

## 🛠️ Tech Stack
- **Language:** Python  
- **Concepts Used:** Functions, File Handling, Conditionals, Loops
